# Lab2_F2400101
## Project Idea
This project explores an algorithm that dynamically adjusts telescope lens frequencies to focus on cosmic events, such as the birth of a new galaxy. By automating lens adjustments, it could help NASA and astronomers capture clearer, more precise images of deep-space phenomena.

## Technologies/Tools Used
- Python (for algorithm simulation)
- NumPy (for calculations)
- Matplotlib (for visualizing focus adjustments)
- GitHub (for collaboration and version control)
